# 🌸 BloomScan – Flower Classification Using CNN

**Official Project Title:** Image Classification Using CNN

BloomScan is an AI-powered flower classification web application that identifies flowers from uploaded images using a trained deep learning model.

🌐 **Live Website:** https://bloomscan.streamlit.app/

## 📌 Project Overview

The project uses Convolutional Neural Networks (CNN) and MobileNetV2 transfer learning to classify flower images into 10 different categories.

Users can upload a flower image and receive:
- Predicted flower name
- Prediction confidence score
- Short description of the identified flower

## 🌼 Flower Categories

1. Rose
2. Sunflower
3. Daisy
4. Tulip
5. Lotus
6. Dandelion
7. Lily
8. Orchid
9. Daffodil
10. Crocus

## 🛠️ Technologies Used

- Python
- TensorFlow and Keras
- MobileNetV2 (Transfer Learning)
- Streamlit
- NumPy
- Pillow
- Git and GitHub

## 🧠 Model Performance

- Model: MobileNetV2 Transfer Learning
- Test Accuracy: **89.77%**
- Test Images: 704
- Image Input Size: 160 × 160 pixels
- Flower Categories: 10

## ⚙️ Application Features

- User-friendly web interface
- Image upload (JPG, JPEG, PNG)
- AI-based flower identification
- Confidence score display
- Flower information and descriptions
- Online deployment using Streamlit Community Cloud

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/maniiitiwari186/flower-classification-cnn.git
```

Open the project folder:

```bash
cd flower-classification-cnn
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
